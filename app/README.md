# Offline navigation (hackathon app)

A webpage for blind and low vision travellers: walking and bus navigation that
keeps working with no signal. Built at the AI Agents for Accessibility
Hackathon, UCL East, 7 November 2026, on the AI for Accessibility Toolkit in
the parent folder.

This is a one-day prototype. It has not been tested beyond one afternoon, it does not tell anyone when it is safe to cross, and it does not replace a cane, a guide dog or orientation and mobility training.

```bash
npm install
npm run dev                         # http://localhost:5173
npm run build && npm run preview    # with offline caching, http://localhost:4173
```
